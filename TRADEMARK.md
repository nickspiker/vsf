# The VSF name

The code is under the Mozilla Public License 2.0 and the specification is under CC BY 4.0. Neither of those covers the name, so this file does.

"VSF", "Versatile Serial Format" and the VSF logo may be used to describe:

0. this repository and the crates published from it;
1. any implementation, in any language, that reads and writes files conforming to the published specification (MEDIA-TYPE.md, colour.md, units.md, idt/);
2. any product, tool or service that reads or writes such files, in the ordinary descriptive sense ("exports VSF", "VSF support").

The name may not be used for a format, encoding or implementation that departs from the specification in a way that is not interoperable with it. A fork that changes the wire is a different format and needs a different name. This is the same rule Fedora, Rust and Python apply to theirs, and it exists for one reason: a file that calls itself VSF must open in every VSF reader.

Nobody needs permission, a logo agreement or a notice to do anything in the list above. Questions about anything else: nick@verichrome.cc.
